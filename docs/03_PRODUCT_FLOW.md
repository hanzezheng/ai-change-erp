# AI农批经营助手业务流程设计

## 1. 核心原则

系统支持两种平等的业务操作方式：

**传统操作**

用户通过订单、客户、收款等业务页面完成操作。

**AI操作**

用户通过底部中央 AI 入口，用语音或文字表达业务，AI理解后驱动同一套业务页面。

最终原则：

> AI不是一套新的业务流程，而是传统业务流程更高效的入口。

------

## 2. AI入口

AI入口固定在底部导航中央。

底部导航：

首页｜订单｜语音按钮｜客户｜更多

### 短按

进入“快速处理”页面。

用于：

- 文字输入
- 查看识别文本
- 相对复杂的表达
- 重新输入或修改

### 长按

直接开始录音。

流程：

长按语音按钮
→ 开始录音
→ 松开发送
→ ASR识别
→ AI理解
→ 执行业务路由

不要求：

点击按钮 → 进入AI页 → 再点击麦克风。

------

## 3. 手动创建订单

订单
→ 新增订单
→ 选择客户
→ 添加商品
→ 填写数量、单位、价格
→ 可继续添加多个商品
→ 填写备注
→ 保存草稿或提交

最终进入 ERPNext Sales Order。

------

## 4. AI创建订单

例如老板说：

> 老韩要20箱八零，再加30件粉蕉，还是之前价格，下午来拿。

处理流程：

语音
→ ASR
→ Intent识别
→ 客户表达解析
→ 商品表达解析
→ 数量/单位/价格表达解析
→ Customer Identity Resolver
→ Product Identity Resolver
→ 查询ERPNext历史数据
→ 生成多商品订单草稿
→ 打开订单编辑页
→ 用户可修改
→ 提交ERPNext

生成结果至少包含：

- 客户
- 多个商品明细
- 数量
- 单位
- 单价或价格来源
- 备注

------

## 5. 多商品订单原则

一张订单可以包含多个商品。

禁止将：

苹果20箱
香蕉30件

拆成两张订单，除非用户明确要求。

AI内部必须使用：

items[]

而不是：

product + quantity

------

## 6. 局部歧义处理

如果一张订单中只有一个字段存在歧义，不要让用户重新描述整个订单。

例如：

- 客户：已确定
- 苹果80果：已确定
- 香蕉：已确定
- 葡萄：规格不确定

系统只询问：

> 葡萄是哪种规格？

确认后继续使用原草稿。

------

## 7. 客户识别

老板可能说：

- 老韩
- 亮哥
- 韩老板
- 韩照亮（ASR误识别）

Identity Resolver 综合：

- 正式名称
- 已确认别名
- ASR历史变体
- 发音相似
- 当前上下文
- 历史纠错

最终映射到 ERPNext Customer。

如果候选唯一且可信，可以继续生成草稿。

如果存在多个合理候选，只询问客户身份。

------

## 8. 修改订单

用户既可以手动修改，也可以通过 AI 修改。

例如当前订单已有：

苹果80果 20箱
香蕉 30件

老板说：

> 苹果改成30箱，再加10箱葡萄。

系统修改当前草稿：

- 苹果 20 → 30箱
- 香蕉保持不变
- 新增葡萄10箱

禁止生成另一张新订单。

------

## 9. 查询

例如：

> 老韩最近都拿什么？

流程：

AI入口
→ 客户识别
→ Spring Boot调用ERPNext查询
→ 打开客户详情或查询结果页

AI负责理解问题。

ERPNext提供正式历史事实。

------

## 10. 收款

手动：

收款页面
→ 新增收款
→ 选择客户/关联单据
→ 金额
→ 支付方式
→ 保存

AI：

> 老王微信收了5000。

流程：

AI理解
→ 客户解析
→ 金额/支付方式解析
→ 生成收款草稿
→ 打开收款编辑页
→ 用户检查
→ ERPNext Payment Entry

------

## 11. 提醒

例如：

> 11点半提醒我给老韩备货。

生成提醒事项。

提醒可以关联：

- 客户
- 订单
- 商品

提醒属于 SaaS 增强能力，不等同于 ERPNext 正式订单状态。

------

## 12. AI失败降级

任何时候 AI 失败都不能影响传统业务操作。

支持：

- 修改识别文本
- 手动选择客户
- 手动选择商品
- 手动编辑订单
- 直接退出AI流程回到业务页面

------

## 13. 企业知识学习

用户纠正结果可以产生知识候选。

例如：

ASR：韩照亮
最终选择：韩兆亮

系统可以形成：

韩照亮 → 韩兆亮

但第一次出现不应偷偷永久写入。

长期身份知识按照：

发现
→ 候选
→ 确认/稳定积累
→ 使用

------

## 14. 最终原则

> 用户可以完全不用AI完成经营工作，也可以通过AI驱动同一套经营系统。

> AI的价值是少点、少输、少找，而不是创造另一套流程。
